# andrewmcdonagh.github.io

Personal portfolio and resume site for Andrew McDonagh — CS senior at UW–Madison graduating May 2026, focused on cybersecurity and backend software engineering.

Live at: **[andrewmcdonagh.github.io](https://andrewmcdonagh.github.io)**

---

## About

This is a single-page static website built with vanilla HTML and CSS — no frameworks, no dependencies, no build step. Designed to be fast, clean, and easy to maintain.

---

## Structure

```
/
├── index.html                  # Main site — all sections in one file
├── Andrew_McDonagh_Resume.pdf  # Downloadable resume (linked from Resume section)
└── README.md                   # This file
```

---

## Sections

- **Home** — Name, tagline, and quick links
- **About** — Background, education, certifications, and interests
- **Projects** — RAG Knowledge System (Hexagon), TimeCoin, Penetration Testing & Threat Modeling, OT/ICS Tabletop Exercise
- **Skills** — Languages, security tools, and engineering stack
- **Resume** — Download link for current resume PDF
- **Contact** — Email, phone, LinkedIn, GitHub, and contact form

---

## Tech Stack

- Pure HTML5 + CSS3 — no frameworks
- Vanilla JavaScript — mobile nav, scroll animations, active nav highlighting
- Hosted on GitHub Pages — free, no server required
- Font stack: Georgia (serif, name/headings) + Helvetica Neue (sans-serif, body)

---

## Design

Minimalist black and white — built to match the aesthetic of the resume. Key design decisions:

- Georgia serif for the name — large, editorial feel
- Hairline borders throughout instead of heavy dividers
- Three-tone greyscale: black for primary content, mid-grey for secondary, light grey for dates and metadata
- Scroll-triggered fade-in animations on all sections
- Fully responsive with mobile hamburger menu

---

## Updating

**To update content:** Edit `index.html` directly — all sections are clearly commented.

**To update the resume:** Replace `Andrew_McDonagh_Resume.pdf` with the new version. Keep the filename the same so the download link doesn't break.

**To deploy changes:** Commit and push to the `main` branch — GitHub Pages rebuilds automatically within a minute or two.
